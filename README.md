# Prediction Market

A simple prediction market built as a Web3 learning project.

### Tech Stack
- React + Vite
- Bun + TypeScript
- Express
- PostgreSQL + Prisma
- Supabase Web3 Auth
- Solflare
- Turborepo

### Run

Frontend:
```bash
cd apps/frontend
bun run dev
````

Backend:

```bash
cd apps/backend
bun index.ts
```

Database:

```bash
cd packages/db
bunx prisma migrate dev
```
